# Session 11 — 2026-11-17

Goal: ten fresh-fixture tasks and a runner that grades independently.

Implemented seven cases, answer-aware subprocess checks, golden/negative/live
modes, durable rows, configuration hashes, standalone summaries, process-group
deadlines and an estimated spend ceiling. No new agent tools or capabilities.

Failures deliberately triggered: unexpected change, no fix, a reversed fix,
half a multi-file change followed by real process death, a hanging checker,
provider 401 on run four, and timeout after partial paid usage. Each retained
the expected failure/error evidence. Already-correct edits and prose-only
boundary refusals fail. A non-golden but correct fix passes.

Observed: scripted 10/10; first live suite 10/10; three repeats 30/30, no flaky
cases. Full regression 605 passed. All 40 saved live-suite answers/workspaces
retained their verdict when regraded after final offline checker refinements.

Learned: this is a useful smoke suite but too small/easy for a quality claim.
Read grading checks identifiers rather than all prose. Generated bytecode must
not affect fixture copies. Keep original rows when changing grader robustness.
